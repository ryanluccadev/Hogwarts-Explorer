# Star Wars Nexus

Abra `pages/planetas.html` ou `pages/naves.html` com o Live Server no VS Code. As duas páginas consultam a [SWAPI](https://swapi.dev/) e a primeira consulta requer internet.

As imagens em `assets/imagens/` foram recortadas do PDF de referência, que não informa suas licenças individuais. O Bootstrap e a fonte Exo 2 estão incluídos com suas licenças.
